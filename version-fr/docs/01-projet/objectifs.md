# AI Daily — Objectifs du projet

## 1. Objectifs du produit

AI Daily a pour objectif de fournir un moyen simple et accessible de découvrir et de comprendre les évolutions importantes dans le domaine de l'Intelligence Artificielle.

Les principaux objectifs du produit sont :

- Centraliser les actualités pertinentes sur l'IA provenant de plusieurs sources.
- Aider les utilisateurs à comprendre rapidement les informations essentielles de chaque actualité.
- Fournir des résumés concis tout en conservant le contexte important.
- Rendre les sources originales accessibles et traçables.
- Réduire le temps nécessaire pour suivre un écosystème de l'IA en évolution rapide.
- Privilégier les informations pertinentes et importantes plutôt que la quantité de contenu.
- Proposer une expérience simple, intuitive et pensée pour le mobile.

## 2. Objectifs d'apprentissage

AI Daily est également un projet pratique d'apprentissage du Software Engineering.

Son développement doit permettre d'acquérir une expérience concrète dans :

- Le développement frontend.
- Le développement backend.
- La conception et le développement d'API REST.
- La conception et la gestion de bases de données.
- L'ingestion et le traitement de données.
- L'intégration de services d'Intelligence Artificielle.
- L'architecture logicielle.
- Le développement d'une Progressive Web App.
- Les tests automatisés.
- La sécurité.
- Le déploiement et l'infrastructure.
- La documentation technique.
- Git et les workflows de développement collaboratif.

L'objectif n'est pas seulement d'apprendre des technologies individuellement, mais de comprendre comment elles fonctionnent ensemble au sein d'un système logiciel complet.

## 3. Objectifs d'ingénierie

AI Daily doit être développé en appliquant des pratiques professionnelles de Software Engineering.

Les principaux objectifs d'ingénierie sont :

- Maintenir une architecture modulaire et facilement maintenable.
- Séparer les responsabilités entre les différentes parties du système.
- Écrire du code clair et compréhensible.
- Documenter les décisions techniques importantes.
- Utiliser Git de manière cohérente pour le contrôle de version.
- Mettre en place des conventions claires pour les commits et les branches.
- Utiliser des tests automatisés lorsque cela est pertinent.
- Prendre en compte la sécurité dès le début du développement.
- Construire le projet progressivement plutôt que tout implémenter en une seule fois.
- Garder les décisions techniques alignées sur les besoins réels du produit.

## 4. Critères de réussite du projet

AI Daily sera considéré comme réussi lorsqu'il démontrera à la fois une réelle utilité pour les utilisateurs et une bonne qualité d'ingénierie.

Le projet doit fournir une expérience utile aux utilisateurs tout en démontrant la capacité à concevoir, développer, tester, documenter, déployer et maintenir un système logiciel complet.
