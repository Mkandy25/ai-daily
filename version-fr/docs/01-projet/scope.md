# AI Daily — Périmètre du projet

## 1. Objectif

Ce document définit le périmètre actuel d'AI Daily et établit les limites du projet.

Le périmètre est destiné à évoluer au fur et à mesure du développement du projet. Les changements importants doivent être documentés lorsqu'ils affectent significativement la direction du produit ou les fonctionnalités prévues.

## 2. Périmètre initial du produit

La version initiale d'AI Daily a pour objectif d'aider les utilisateurs à découvrir et comprendre les actualités pertinentes liées à l'Intelligence Artificielle.

Le produit initial doit inclure :

- Un flux d'actualités liées à l'IA.
- Des actualités organisées par catégories pertinentes.
- Une page dédiée à chaque actualité.
- Un résumé concis de chaque actualité.
- Des informations contextuelles permettant de mieux comprendre l'actualité.
- Un accès à la source originale.
- Une fonctionnalité de recherche basique.
- Une interface responsive et pensée pour le mobile.
- Les fonctionnalités principales d'une Progressive Web App.

## 3. Périmètre du contenu

AI Daily peut couvrir notamment :

- Les modèles d'Intelligence Artificielle.
- Le Machine Learning.
- L'IA générative.
- Les outils et plateformes d'IA.
- La recherche en IA.
- Les entreprises et produits liés à l'IA.
- Les évolutions majeures de l'écosystème de l'IA.

Le projet doit privilégier les évolutions pertinentes plutôt que d'essayer de collecter toutes les publications liées à l'IA.

## 4. Périmètre technique initial

Le projet couvrira progressivement :

- L'application frontend.
- L'API backend.
- La base de données.
- Le pipeline d'ingestion et de traitement des actualités.
- Le traitement du contenu assisté par IA.
- Les fonctionnalités PWA.
- Les tests automatisés.
- Le déploiement.

Les choix technologiques pourront évoluer au cours du développement.

## 5. Périmètre futur

Les fonctionnalités suivantes pourront être envisagées après la version initiale :

- Flux d'actualités personnalisé.
- Recommandations de contenu.
- Notifications.
- Explications générées par IA pour les concepts techniques.
- Analyse des tendances.
- Comparaison de plusieurs sources traitant d'un même événement.
- Filtres avancés.
- Comptes utilisateurs et préférences.
- Informations destinées aux développeurs pour expliquer pourquoi une actualité peut être importante pour eux.

Ces fonctionnalités ne font pas partie du périmètre initial, sauf si elles sont explicitement ajoutées ultérieurement.

## 6. Hors périmètre

AI Daily n'a pas pour objectif de devenir :

- Un réseau social généraliste.
- Un remplacement des sources d'information originales.
- Un moteur de recherche généraliste.
- Une plateforme permettant la publication libre de contenus d'actualité par les utilisateurs.
- Un chatbot IA généraliste.
- Une plateforme couvrant tous les domaines technologiques.

Ces limites permettent de conserver une direction produit claire.

## 7. Évolution du périmètre

Le périmètre d'AI Daily peut évoluer d'une version à l'autre.

Les changements importants doivent être documentés et associés à une version ou à une étape spécifique du projet.

Le périmètre doit toujours rester cohérent avec la vision, les objectifs du projet et les ressources de développement disponibles.
